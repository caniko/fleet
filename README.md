# fleet

Integration superproject for fleetix, canix-toolbelt, infernix, nix-manager-core,
secret-manager, dns-manager and bootswain. Each component stays its own
repository (gitlinked under `components/`) and keeps its own releases.

Fleet CI qualifies the gitlinked revisions together: sibling flake inputs follow
the gitlinked checkout, so consumers are always tested against the producer
revisions they will ship with. CI is generated by simit from `simit.toml`.

To qualify a component change, open a fleet PR that moves its gitlink to the
component PR head; merge the component once fleet's `qualified` check passes.

    git clone --recurse-submodules https://github.com/caniko/fleet
